# Ocean's Delight - Unofficial Port

Prepare seafood dishes using Farmer’s Delight cooking and cutting recipes.

Original: [Scouter456 (scouter567 on CurseForge)](https://www.curseforge.com/minecraft/mc-mods/oceans-delight) ([source](https://github.com/Scouter456/Oceans_Delight), upstream commit 70fe769a71b0ff584b8a0164af62e4cb9fd8699a). Maintained independently by Gorbachof.

## Install

Minecraft 26.3, NeoForge 26.3.0.118, Java 25. Place the JAR from [Releases](https://github.com/JGorbachof/oceans-delight-26-3/releases) in the mods folder on client and server.
Requires [Farmer's Delight Neoforged](https://www.curseforge.com/minecraft/mc-mods/farmers-delight-neoforged) 1.3.4 or later compatible with 26.3 (tested 1.3.4-3).


## Testing

Native server recipe loading, tentacle smelting and guardian and squid loot conditions passed. Cooking pot and cutting board recipes registered; operation and rendering remain untested. Client rendering and extended gameplay remain unverified. This is an alpha release.

## Build

Use Java 25 and the included Gradle wrapper: gradlew.bat jar (Windows) or ./gradlew jar (Linux/macOS). The published binary includes the original license and NOTICE; packaging-only additions may differ from the native-tested build hash.
